# CLAUDE.md

Project: Tangible Interface. three.js viewer on GitHub Pages with two stations (sensor `/sensor/`, AR `/ar/`) sharing `shared/viewer.js` and one GLB.
Guiding principle: **keep it simple**: static files, no build tools, three.js 0.187.0 from jsDelivr via an import map.

**Current values (colours, lights, background, camera, conventions, AR notes): `docs/viewer-settings.md`.**

## Conventions
- Stations are thin input adapters that call `model.setTargetOrientation(yaw, pitch)` or `setTargetQuaternion(q)`; smoothing and mode switching live in `viewer.js`.
- Rotation = Rx(-pitch) · Ry(yaw). Yaw is read back with `atan2(m[8], m[0])`, which doesn't depend on pitch.
- Modes: 0 flat (`flatShading`, no maps), 1 smooth + aoMap + normalMap (normal map optional), 2 original GLB material. Hard switch at 60/180/300°.
- AR: MindAR 1.2.5 needs `shared/three-compat.js` (adds the removed `sRGBEncoding`); the import map in `ar/index.html` points only MindAR's `three` there. Card + target are generated by `tools/make_card.py` from the artwork `ar/design.pdf` (120 mm; `TARGET_MM = 138` in `ar/index.html`); recompile `ar/target.mind` with `tools/compile-target.html` whenever `ar/target.png` changes.
- The GLB has no Draco compression (no DRACOLoader on purpose). The AO is baked into the GLB's occlusion texture.
