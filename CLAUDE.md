## Conventions
- Stations are thin input adapters that call `model.setTargetOrientation(yaw, pitch)` or `setTargetQuaternion(q)`; smoothing and mode switching live in `viewer.js`.
- Rotation = Rx(-pitch) · Ry(yaw). Yaw is read back with `atan2(m[8], m[0])`, which doesn't depend on pitch.
- Two views: 0 X-ray (fresnel `ShaderMaterial` from `makeXrayMaterial()`, normal blending, steel blue), 1 original GLB material (full PBR). Hard switch at 90° / 270° (X-ray = front half 270°–90°). No key light any more; `RoomEnvironment` stays for PBR. Change request: project doc `claude/xray-change.md`.
- AR: MindAR 1.2.5 needs `shared/three-compat.js` (adds the removed `sRGBEncoding`); the import map in `ar/index.html` points only MindAR's `three` there. Card + target are generated by `tools/make_card.py` from the artwork `ar/design.pdf` (120 mm; `TARGET_MM = 138` in `ar/index.html`); recompile `ar/target.mind` with `tools/compile-target.html` whenever `ar/target.png` changes. MindAR's fixed 45° camera FOV is patched in `ar/index.html` (`tune.fov`, default 66° across the video's long side, iPhone 16).
- The GLB has no Draco compression (no DRACOLoader on purpose). The AO is baked into the GLB's occlusion texture.
